1. React 组件 与 JSX/TSX

React组件使用 jsx/tsx 编写，最纯粹的js/ts开发。React组件可以是一个方法，也可以是一个class类。可以在js/ts文件中写一段html作为一个组件，可以可一个单独的jsx或js/tsx或ts文件。

React 组件分类：1. 函数组件；2. Class 组件。

JSX 的特点：

  1. 可以直接写在js文件中：React项目利用babel做了对js的编译。
  2. JSX几乎和js一样，不同点在于，可以更方便的写html在js里。

7. React 的生命周期

React 主要的生命周期：

渲染时期（Mount）：

  1. render：渲染之前，执行render决定模版。
  2. componentDidMount：已经完成了渲染。

更新时期（Update）：

  1. shouldComponentUpdate：是否应该重新渲染。
  2. componentDidUpdate：完成更新时。

卸载时期（Unmount）：

  1. componentWillUnmount：即将卸载时。

React 18开发模式下生命周期整个执行过程：

  1. 先按正常流程走一遍：constructor → render → useEffect(mount) → useEffect(update)。
  2. 立即把组件卸载（触发 cleanup）。
  3. 再重新挂载一次（触发第二次 mount + update），用来帮你检查副作用是否可重入、有没有内存泄漏。

15. React 的路由 router

React 路由：

  1. react-router-dom：应用在浏览器端运行的项目。
  2. react-router：应用在React服务端渲染。

React 路由相关概念：

  1. HashRouter/BrowserRouter：决定路由模式是hash模式还是history。
  2. Routes：页面显示容器。
  3. Route：定义具体的路径与页面。

获取路由中的数据：

  1. 获取params：useParams（v6）/this.props.match.params（v5）
  2. 获取search：useSearchParams（v6）/this.props.location.search（v5）
  3. 获取params：useLocation（v6）/this.props.location.state（v5）

路由JS跳转：useNavigate(v6)/this.props.history.push()(v5)

17. React 渲染性能优化

  1. 数据只加载一次时或者仅仅只有某个属性发生变化后才进行调用时，使用 useMemo() 方法。
  2. 路由使用子组件所有属性都依赖于父组件时，可以集成 React.PureComponent 或者使用 memo() 方法。当传入子组件含有方法时，可以将方法通过 useCallback() 方法进行包裹。避免父组件重新渲染方法重新生成。
